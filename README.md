# Dr. Bernardo Corrêa — Instagram / Marca

Projeto de branding, direção de arte e estratégia de conteúdo para o Instagram do Dr. Bernardo Corrêa (ortopedista, Cirurgia da Mão — UNIFESP).

## Estrutura

```
/brand
    /colors       → paleta oficial (brand/colors/palette.md)
    /fonts        → sistema tipográfico (brand/fonts/typography.md)
    /logos        → arquivos de logo/wordmark/monograma
    /guidelines   → Brand Guidelines central (brand/guidelines/BRAND_GUIDELINES.md)

/templates
    /reels        → templates de capa de Reel
    /stories      → templates de Stories
    /carousels    → templates de carrossel
    /posts        → templates de post estático

/content
    /reels        → peças finais de Reels
    /stories      → peças finais de Stories
    /carousels    → peças finais de carrossel
    /campaigns    → materiais de campanha/anúncio

/assets
    /photos          → fotografia real
    /medical         → exames, radiografias, ultrassom, ressonância
    /illustrations   → ilustrações anatômicas
    /icons           → elementos gráficos e ícones
    /references      → exemplos e prints trazidos como referência (mood board)

/archive          → materiais descontinuados
```

## Ponto de partida

Comece por [`brand/guidelines/BRAND_GUIDELINES.md`](brand/guidelines/BRAND_GUIDELINES.md) — reúne posicionamento, público, regras de identidade verbal (evergreen), identidade visual, paleta, tipografia, formatos e checklist de qualidade. Toda peça nova deve ser conferida contra esse documento antes de ser considerada pronta.

Pendência registrada na seção 15 do documento: confirmação de disponibilidade das fontes propostas (Montserrat/Aeonik e Fraunces/Playfair Display) nas ferramentas de produção.
